# Solva – ระบบจัดการร้านทำเล็บ

เว็บแอปจัดการร้านทำเล็บ พัฒนาต่อจากต้นแบบ Claude Design (`design/solva-design.html`) ให้เป็นแอปที่ใช้งานได้จริง ข้อมูลทุกหน้าเชื่อมกัน และบันทึกไว้ในเบราว์เซอร์ (localStorage)

## เริ่มใช้งาน

```bash
npm start          # หรือ python3 -m http.server 8080
# เปิด http://localhost:8080
```

ไม่ต้อง build และไม่มี dependency เปิด `index.html` จากเครื่องตรง ๆ ก็ได้

บัญชีทดลอง: `owner@solva.demo` / `solva1234` (หรือ `manager` / `solva1234`)

## ฟีเจอร์

| หน้า | ใช้ทำอะไรได้ |
|---|---|
| เข้าสู่ระบบ | เข้าสู่ระบบ สมัครสมาชิก ลืมรหัสผ่าน (เดโม) จดจำผู้ใช้ และกันไม่ให้เข้าหน้าอื่นถ้ายังไม่ล็อกอิน |
| ภาพรวม | คิววันนี้และคิวถัดไป ปฏิทินที่บอกว่าวันไหนคิวแน่น (กดวันที่เพื่อเปิดตารางนัด) รายได้วันนี้เทียบเป้า ตัวเลขสรุป และการแจ้งเตือน |
| ตารางนัด | เลือกวันจากแถบสัปดาห์ กรองตามช่าง/สถานะ เตือนคิวซ้อน ดูการใช้เวลาของช่าง เพิ่ม/แก้ไขนัด (มีราคารวมและเตือนคิวทับ) ยืนยันนัด ให้บริการเสร็จ ไม่มาตามนัด ยกเลิก รับชำระเงิน + ทิป บันทึกบิลหรือตารางทั้งวันเป็น PNG |
| ลูกค้า | กรองตามระดับสมาชิก ค้นหา เรียงลำดับ เพิ่ม/แก้ไขลูกค้า สมัคร/อัปเกรด/ต่ออายุ/ยกเลิกสมาชิก (ส่วนลดใช้กับนัดที่ยังไม่ชำระทันที) โน้ต สรุปการใช้บริการ ประวัติ และส่งออก CSV |
| พนักงาน | สถานะเข้างานวันนี้ ลงเวลาเข้า/ออก บันทึกลา ชั่วโมงทำงานรายสัปดาห์และรายเดือน ทักษะหลัก/รอง ค่าคอมและทิปที่คำนวณจากงานจริง จ่ายยอดค้าง และรายงานค่าคอมเป็น PNG |
| การเงิน | ดูทีละเดือน (รายได้ ค่าใช้จ่าย กำไร ค่าคอม) เทียบกับช่วงเดียวกันเดือนก่อน กราฟ 7 เดือน วงกลมความคืบหน้าเทียบเป้า สัดส่วนค่าใช้จ่าย เพิ่ม/แก้ไข/ลบรายรับรายจ่าย และส่งออก CSV |
| สต็อก | สถานะสินค้า (ปกติ/ใกล้หมด/หมด) มูลค่าสต็อก บันทึกรับเข้า/เบิกออก (กันเบิกเกินที่มี) สั่งซื้อเติมสต็อกพร้อมบันทึกรายจ่ายอัตโนมัติ และประวัติการเคลื่อนไหว |

ส่วนที่ใช้ร่วมกันทุกหน้า: ค้นหาลูกค้า นัดหมาย พนักงาน และสินค้า; กระดิ่งแจ้งเตือน; เมนูบัญชีสำหรับส่งออก/นำเข้าข้อมูล JSON, รีเซ็ตข้อมูลเดโม และออกจากระบบ รองรับหน้าจอมือถือ (เมนูย้ายไปด้านล่าง)

## โครงสร้าง

```
index.html            จุดเริ่มต้นของแอป
css/styles.css        สไตล์จาก design + modal/ฟอร์ม/dropdown
js/util.js            ฟังก์ชันช่วยจัดรูปแบบ วันที่ไทย (พ.ศ.) CSV
js/store.js           ข้อมูลตัวอย่าง การบันทึก localStorage และฟังก์ชันคำนวณค่าต่าง ๆ
js/ui.js              ตัว render (DOM morph) router เปลือกแอป modal toast และตัวสร้าง PNG
js/forms.js           ฟอร์มที่ใช้ร่วมกัน (นัดหมาย ชำระเงิน ลูกค้า พนักงาน รายรับรายจ่าย สินค้า สต็อก)
js/pages/*.js         หน้าต่าง ๆ แยกไฟล์ละหน้า
tests/store.test.js   unit test ของชั้นข้อมูล (npm test)
design/               ไฟล์ต้นแบบจาก Claude Design
```

ข้อมูลตัวอย่างสร้างย้อนหลังประมาณ 7 เดือนโดยอิงวันปัจจุบัน ถ้ายังไม่ได้แก้ไขข้อมูล ระบบจะสร้างใหม่ทุกวัน เพื่อให้ "วันนี้" มีคิวเสมอ เมื่อมีการแก้ไขแล้ว ข้อมูลจะถูกเก็บไว้ตามเดิม

## ข้อจำกัด / งานถัดไป

- ยังไม่มี backend: บัญชีผู้ใช้และข้อมูลทั้งหมดเก็บในเบราว์เซอร์เครื่องเดียว และรหัสผ่านไม่ได้เข้ารหัส ใช้เป็นเดโมเท่านั้น
- ขั้นต่อไปที่แนะนำ: ต่อ API และฐานข้อมูลจริง, กำหนดสิทธิ์ตามบทบาท (เจ้าของ/ผู้จัดการ/ช่าง), แจ้งเตือนลูกค้าผ่าน LINE, และรับชำระด้วย QR PromptPay
